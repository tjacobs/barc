# BARC — Build Plan

## What exists now
- `index.html` — landing page, invite-only framing, your email as contact
- `discord-structure.md` — full channel/role layout ready to implement

---

## Phase 1 — Launch (Week 1–2)

### You do
- Create the Discord server using `discord-structure.md` as the blueprint
- Invite your first 5–10 people manually
- Host the landing page (Netlify drop or GitHub Pages — both free, 2 minutes)

### I can do on your command
- Write a short personal invite message you can send to each person
- Write the `#start-here` pinned message for Discord
- Write onboarding DM text for when someone joins as Guest

---

## Phase 2 — First Meetup (Week 3–6)

### I can prepare
- Venue shortlist: researched options in Palo Alto (makerspaces, library rooms, Stanford-adjacent)
- Event page copy for Meetup.com or a simple invite
- Meetup agenda template (intros → demos → open discussion → next steps)
- Demo submission format — what builders should prep to show

### Format suggestion for first event
- 2 hrs, 6–10 people
- 3–4 short demos (10 min each): what you built, what was hard, what's next
- 30 min open discussion — research, tools, what everyone's watching
- No slides required, robots welcome

---

## Phase 3 — Ongoing Operations (Monthly)

### I can run on a schedule
- **Weekly**: surface 3–5 notable robotics papers, builds, or hardware releases for your review — you pick what to share to Discord
- **Monthly**: draft a newsletter/digest for the `#announcements` channel
- **Pre-meetup**: generate an agenda draft based on submitted demos

### Community health
- Membership vetting: I can draft questions to ask prospective members
- Write a "how we run things" doc once patterns emerge from early meetups
